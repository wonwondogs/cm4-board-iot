# Licensing

## Scope

Licensing is tracked separately for project-owned documentation and images, the STM32 application, and third-party firmware components. A repository-wide license has not yet been selected.

The current repository distributes documentation and presentation assets. It does not distribute the STM32 firmware binary or library source.

## Documentation and images

Reuse terms for the project-owned text, diagrams, and photographs remain to be selected before publication. The presence of third-party license texts does not apply those licenses to the project-owned materials.

## STM32 firmware

The current CM4 Carrier Board is planned for a future open release of its editable hardware design files and firmware source code. The release scope and licenses have not yet been finalized. The candidate firmware statically links libopencm3, whose project license is LGPL-3.0-or-later.

The planned firmware package will include the application source, the corresponding library source and notices, build instructions, and the applicable license terms. These materials must be assembled and checked against the release binary. The license texts in this repository are reference copies; their inclusion alone does not make the firmware package ready for redistribution.

See [third-party notices](THIRD_PARTY_NOTICES.md) and [release preparation](docs/release-status.md).

## R7

R7 is a separate development project. Its release plans and licensing have not been decided. The R7 preview images do not imply a commitment to release its design files or firmware source code.
